ClutchAI is decision support, not financial advice. It never moves money or makes irreversible changes without you clicking the button yourself. All data lives only in this browser (localStorage). "Can I go?" is connected to a real Gemini-powered backend by default — your questions go from your browser to that backend, which calls Google's Gemini API using a key that lives only on the server, never in this app or in GitHub. If the backend is ever unreachable, it falls back to a simulated estimate computed entirely in your browser.
